# Research source archive

This is a recovery archive of the project's FP16/INT8 experiments and reports, separate from the accepted game build. See [recovery guide](../../docs/RECOVERY.md) and [portable tools](../../tools/experiments/README.md).

INDEX.json lists every published file, its original workspace-relative location, original SHA256 and published SHA256. Workstation roots use named placeholders. Historical executable scripts are stored as text and restored only on explicit request. Generated outputs, model assets, captured frames and vendor environments are excluded; preserve those in private storage.

Only indexed files form this archive. Current default model selection remains tools/model_profiles.json. Archived failures, superseded tasks and exploratory conclusions retain their historical context and do not override the accepted build.

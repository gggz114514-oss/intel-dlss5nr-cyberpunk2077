# Two-lane norm tree, paired Q/K coefficient consumption

This candidate adjusts the prior norm-local-owner implementation. Performance baseline remains f20-score-owner; neither prior experimental norm variant has been accepted.

## Preserve the expression tree, distribute its branches

For each row, the original tree has s[c]=(sq[c]+sq[c+16])+(sq[c+8]+sq[c+24]), t4[c]=s[c]+s[c+4], t2[0]=t4[0]+t4[2], t2[1]=t4[1]+t4[3], sum=t2[0]+t2[1]. Do not replace this with independent contiguous half-row sums.

Lane id low4bits selects one of16 norms (Q rows0..7,K rows0..7). Lane bit4 selects even or odd c branches. Each lane evaluates16 square leaves, four s nodes, two t4 nodes and one t2 node. One xor16 bit-preserving half exchange supplies t2[1] to the even lane; that lane computes the original final addition, floor, inversesqrt and half narrowing. All32 lanes execute the long square/branch work; only16 execute the small root. There are no duplicate squares or extra inversesqrts. The builder compares the complete ordered symbolic trees and enumerates512 unique square leaves per subgroup.

Source tree preservation does not prove identical JIT contraction. No scalar norm NoContraction is added; original fold/scale/bias decorations are preserved. Fixed/fb2 exact gates are required. A failure is retained and not relabeled an acceptable approximation.

## Pair coefficients and end their lifetime earlier

One xor8 exchange pairs Q/K coefficients for the same row. Lanes0..7 hold packed(Q,K). Four broadcasts each fetch both coefficients for a consumer row. Q register scaling and K shared scaling now execute together, preserving each value's half multiply sequence. Total coefficient/root exchange calls are6 per subgroup:1 partial xor16,1 coefficient xor8,4 paired broadcasts, versus8 separate coefficient broadcasts previously. No shuffle-based floating conversion is used; packFloat2x16/unpackFloat2x16 only transport bits.

Coefficient carrier retires before the normalized-K publication barrier, instead of surviving into score. The raw norm array per active lane shrinks32→16 half elements, s8→4. Q's existing16B/lane retained payload is unchanged. Packing/select temporaries are extra costs. These source payloads are not physical GRF allocation or occupancy measurements.

Original QKV publication and normalized-K publication remain, and subgroupBarrier retires own-row raw norm reads before K overwrites. No shared norm slab is reintroduced. Shared declaration24576B; weights and eight-subgroup organization unchanged. The score/den/PV/output arithmetic is unchanged.

CPU compilation, SPIR-V validation, plan validation and mapping/tree checks are complete. GPU gate/native/ordinary/resource decisions are recorded separately. Main owns analysis/code, Luna executes the explicit validation manifests only. Do not adopt based on full-lane participation or fewer shuffle calls; accept only an exact no-spill candidate with demonstrated net gain.

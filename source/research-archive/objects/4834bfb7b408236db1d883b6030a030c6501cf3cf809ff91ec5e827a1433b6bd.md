## K/V consumer tiles and K reuse

K producer tile index = feature16*1024 + keySG*256. Each natural token8×feature16 CH fragment writes column-major16 into that tile. Consumer B sees feature16×key16 row-major16. V tile index = keySG*512 + feature16*256; producer and consumer both use row-major16. The two8-token fragments fill complementary128-half regions. Exhaustive producer coordinates cover all2048half slots once for bothK andV; consumer coordinates match all4096half elements checked, no extra shared storage.

For each key16 block, load K feature0..15 once and immediately consume with both query8 accumulators; then load feature16..31 once and consume both. Each scalar score retains K0 thenK16 and the same bias-add/narrow/exp order. K B-load source sites16->8 and logical requests8192->4096B/SG. V requests remain4096B/SG. This is twoquery consumption of one loaded block, without keeping a full K cache live. Two score accumulators are temporarily live instead of one, so the local score-accumulator payload increases16->32B/lane; final physical pressure must be checked in native.

## Coefficient owner

The norm and den ordered sum trees are unchanged. Only coefficient evaluation and distribution move to query owners. Each of32 lanes owns query=lane%16, matching the twofold hardware-lane replication of the old query-centric implementation rather than recomputing each coefficient across all16feature lanes.

Norm sum packets ns[d] belong to query2*d+(lane>>4). Choose d=(lane>>1)&7 locally, then shuffle from (lane&14)|((lane&1)<<4). The receiving lane has its own query's Q/K sums. Evaluate rsqrt twice, pack Q/K coefficients together, and distribute to eight natural component rows. Symbolic enumeration verifies all256 coefficient consumers.

Den sum packets ds[d] hold queries4*d+parity and4*d+2+parity. Select packet(lane>>2)&3, use the same source-lane permutation, then select component(lane>>1)&1. Evaluate one reciprocal perlane. Pair coefficients using xor2, then distribute four two-query packets. All256 consumers were checked. Neither tree is replaced with a different reduction order; the zero seed, clamp, reciprocal rounding and P multiply remain intact.

Expected math sites: rsqrt16->2 and inverse8->1. Added packed shuffles: norm9, den6, total15. These are explicitly charged, not hidden in a claim of free broadcasting. SLM layout and traffic unchanged in this independent arm.

V is published before retaining the eight norm sum packets. The32B/lane packet payload replaces the32B/lane V payload in that region rather than extending both lifetimes. Den adds fouruint sum packets16B/lane while P remains live; it does not create FP32 projection accumulators early. These are logical source payloads, not a physical peak-GRF proof. No added scratch sends allowed for timing approval.

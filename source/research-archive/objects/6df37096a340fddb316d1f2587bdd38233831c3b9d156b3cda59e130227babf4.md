# 成本账（静态，不是计时结果）

所有数字来自计划/包文件与源码，**没有任何 GPU 计时**；不得把“静态所以免费”当结论。

## 当前最佳 arm（C64 family static）
- 每 block scale pack 1856 → 2368 B（+512 B，+64 inverse +64 residual half 常量），8 blocks → +4096 B 常量。
- 每 block weight pack 28672 B 不变；SPV 替换 2 个/block（qx producer + contract），共 16 个。
- contract 残差改读原 half X：新增一次 half 读（8,257,536 B/block 级输入），**读取成本/缓存压力未测**。
- 无新增 dispatch、无新增 barrier、无 SLM 扩容；K32 寄存器路径保持。
- 速度：UNMEASURED。

## C32 body1-3 equalization
- 每 block scale pack 1168 → 1296 B（+128 B，32 个逐输入通道 inverse），3 blocks → +384 B。
- weight pack 49152 B 不变；每 block 1 个 SPV；无新增 dispatch。
- quantizer 多一次 per-channel inverse 读（32 floats，常量缓存）；无运行时归约。
- 速度：UNMEASURED。

## C32 tail 67-69（边际候选）
- 每 block scale 1168 → 1296 B（+128 B），3 blocks → +384 B；weight 49152 B 不变；3 个 SPV。
- 无新增 dispatch；速度：UNMEASURED。
- 24 帧实测 +0.0023 dB，3/24 轻微退化；不是性能候选。

## C32 body4 E 候选（已否决）
- scale 1296 → 1808 B（+512 B）；weight 49152 B 不变（只改 contract 区 3728 B）。
- 无新增 dispatch；但整网 -0.25 dB，成本账无意义，保留作负结果。

## C128 b9（阻塞）
- weight 106496 B 不变；scale 4160 B 不变（复用 `sc[912+c]` 槽）；无新增 dispatch。
- gate 失败，先修语义再谈成本。

## C256 b15（未采纳）
- pack 5,537,792 B 不变（只改前 374,912 B）；无新增 dispatch；scale 8,842 B 不变。
- 2/3 帧轻微退化；先 gate。

## 静态 attention（尚未实现）
- S09 设计：ViT sQ+sK 改成 per-head 静态常数，可去掉 `OpAtomicUMax` 的跨 SG 归约；scale 表 128 → 512 B（ViT），必须同步所有 BIND。
- 代价：每 head 多 2 个常量读；收益是去掉 atomic/reduction，但**未计时**。
- P 必须保留 per-query 动态（静态 1/127 误差 23×、2.89% 饱和），不能为了“全静态”强行替换。

## 结论
- 当前所有“收益”都是画质/局部误差，不是速度；没有任何端到端计时。
- 质量稳定后才做同批配对计时（含 scale 读取、额外 dispatch、输出转换），不能用单核时间代替。

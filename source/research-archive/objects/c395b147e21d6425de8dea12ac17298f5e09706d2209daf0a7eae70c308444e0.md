# NATIVE-PREDICTION — n18-f01-entry

不是“已实现”，是**预测 + 判据**。全部观察点在 ordinal 0（`f1c32_image_pre`，kernel hash `5bd64f2b0906027c`，SIMD32）的 ISA 里可直接数，无需计时。
基线数字取自 `queue/n09c-f09-b-share/native/captures/native-native-base/ISA/CS_asm5bd64f2b0906027c_simd32_0000000000000001_0_orig.asm`（当前链头，与 ord 0 的 SPV 同一 native hash）。

## 1. 首要判据（落到 native 的充分条件）

| # | 可观察点 | 基线 | 预测 | 若看不到 |
|---|---|---|---|---|
| 1 | `mul (16|M0) acc`（`i%period` 的 32×32→64 低半乘） | **31** | **≤14**（期望 12–14） | 归 A：实现未落地，不许用毫秒反推 |
| 2 | `mul (16|M16) acc` / `macl (16|M0)` / `macl (16|M16)` | 31 / 31 / 31 | ≤14 / ≤14 / ≤14 | 同上 |
| 3 | 入口区（首条 gather 到 feature pack 结束）热指令 | 1491 | 1150–1300 | 同上 |
| 4 | 全核静态指令（驱动 Instruction Count） | 7165 | 6850–6950 | 同上 |

4 条互相独立：1/2 是“取模序列真的消失”，3/4 是“总量真的缩小”。**任何一条不动而总量却变小，说明是别的 pass 或调度在变，不能归因本机制。**

## 2. 必须保持不动的观察点（防止误判成“别的改动生效了”）

| # | 可观察点 | 基线 | 要求 |
|---|---|---|---|
| 5 | `load.ugm.d32.a32.bss` 标量 gather 消息 | 73（`[a0.0]` 28 / `[A+0x4]` 23 / `[A+0x8]` 22） | **仍 73**，立即数分布不变（地址值不变，只删算法） |
| 6 | gather 的 exec size | 全部 `(32|M0)` | 仍 32（本卡不动 lane 映射） |
| 7 | `mov` 的 `hf←f` | 入口 24 / 全核 489 | 不变（未增删舍入点） |
| 8 | `dpas.8x8` / `math.inv` / `rndd` / `frc` | 132 / 13 / 10 / 6 | 不变 |
| 9 | `send.ugm` 热路径总数 / `store.slm`·`load.slm` | 272 / 32 | 不变（±1 由调度 padding 造成可接受，但同族消息数必须同） |
| 10 | Scratch / SLM | 0 B / 9216 B | 不变 |
| 11 | 基本块数（驱动 Basic Block Count） | 179 | 允许 ≤179（删分支不新增）；若**上升**说明新增了分支，需解释 |

## 3. 期望的次要形态（弱判据，用于判 B 类副作用）

* `sel`（入口 151）与 `cmp`（入口 104）应各降 5–15（反射选择消失）。
* `sync.nop`（全核 216）可能同量变化：它只是调度 padding，不单独作为判据。
* 若 `mul (16|M0) acc` 降到 ≤14 但 `sel` 反而上升：说明 IGC 把删掉的选择换成了别的选择（副作用），记 B 类并定位。
* 若静态指令下降 ≥170 但 `max_r`（GRF 峰值）上升：说明调度把省下的时间换成了寄存器压力，记 B 类。

## 5. 归因边界

* 本卡 plan 与链头 plan 只差 PASS 0 的 SPV 路径 1 行（已核实 2 行 unified diff），其余 231 个 PASS 字节相同 → 整帧差只能来自 F01。
* 但 F01 内部同时有 gather/转换/矩阵三段；ISA 判据（第 1 节）只证明“取模序列消失”，**不证明**这 1.164 ms 的下降全来自它。若需要更强归因，做 ablate：把 `nrf_rgba_clamped` 换回 `nrf_rgba` 的第二个候选（同卡内可生成，见 RESUME）。

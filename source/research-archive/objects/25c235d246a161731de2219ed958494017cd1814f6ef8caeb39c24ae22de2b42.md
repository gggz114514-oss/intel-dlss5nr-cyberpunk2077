# ANALYSIS — n18-f01-entry（F01 / ordinal 0 / `f1c32_image_pre`）

候选机制：**入口 gather 的镜像取模恒等删减**（成本类 = 地址计算）。
父：`c32-boundary-candidates-20261026/f01-direct-a/candidate.comp`（sha `03ba479a…`）→ 基线 SPV `31c2fd9a…`（本卡 `parent-rebuild.spv` 用 RECIPES 的 nc_recipe 字节复现，`decorated_match=true`，NC 189/189）。
候选：`candidate.comp`（sha 见 BUILD.json）→ `candidate.spv`。

---

## 1. 映射：每个 (lane, component) 代表哪个 (token, feature)，消费者要什么

### 1.1 生产者 → 输出 token

`nrf_prepare_A(q=sg)`，`lane<16` 的 16 条 lane 各产出 **1 个 token 的 16 个 feature**：

```
token      t  = 16·q + L                       (q = sg = 0..3，L = lane 0..15)
pixel      px = WGID.x·8 + 4·(q&1) + (L%4)     py = WGID.y·8 + 4·(q>>1) + (L/4)
```

覆盖性：一个 WG 的 4 个 SG × 16 lane = **64 个 token = 8×8 tile 的每一像素恰好一次**（`(q&1, q>>1)` 选 4×4 子块，`L%4, L/4` 选块内像素），无重叠、无遗漏。

### 1.2 16 个 feature 槽（固定，`packed[0..7]` = 8 个 dword = 16 个 half）

| j | 值 | 来源 | 分支 |
|---|---|---|---|
| 0,1 | 噪声 x,y | 冷噪声 `f[ni..ni+2]`（`p5.w&4`）或 PCG 高斯 | 统一分支 |
| 2 | 噪声 z | 同上 | |
| 3 | `ctl(6)` | 控制常量（uniform） | |
| 4,5 | centered r,g | `(sampled-0.5)·0.125`（f16） | |
| 6 | centered b | 同上 | |
| 7,8,9 | history r,g,b | `nrf_history5`（f32）→ f16 | `ctl(8)!=0` |
| 10,11 | `ctl(0)`,`ctl(1)` | uniform | |
| 12,13 | `ctl(2)`,`ctl(3)` | uniform | |
| 14 | `ctl(4)` | uniform | |
| 15 | 0 | 常量 | |

### 1.3 消费者要求

* 写：`shK[q·256 + L·16 + j]`（half），两条 `store.slm.d32x4`（16 B/lane ×2 = 32 B/lane = 16 half/lane）。
* 读：`subgroupMemoryBarrierShared(); subgroupBarrier()` 之后 `coopMatLoad(a0, shK, q·256, 16, RowMajor)` 与 `coopMatLoad(a1, shK, q·256+128, 16, RowMajor)` = 两个 8×16 A 片段（token 0–7 / 8–15，K = 16 feature）。
* 用：`nrf_lift` 的 `acc[token][n] = Σ_k feature[token][k] · w[n][k]`，K 维就是 16 个 feature；`n = 8` 个输出通道 × 4 个 lift 组 = 32 通道。

### 1.4 一一覆盖断言

| 断言 | 证据 |
|---|---|
| 每个 (token, feature) 写一次 | 单一 `shK[...]=` 序列，16 个半字写；`lane<16` 内层无重复 |
| 每个 (token, feature) 读一次 | `a0`/`a1` 各 16 条 `ld.slm` 元素，K=16 全用 |
| 无漏读 | K 维 16 = packed 槽位 16 |
| 无重复写 | shK 的 `q·256` 区间按 SG 划分，4 SG 互不重叠（0–255/256–511/512–767/768–1023） |
| 无效 lane 不写 | `if(lane<16u)` 围住两次 `shK` 写 |
| 尾块 | token 越界由 `tok_oob`（`pc.p0.x`/`pc.p3.z` 的 tile 边界）统一门控输出 store；输入像素用 mirror 折回，无 OOB |

**本卡不改这个映射的任何一项**：只把 4 个历史角点读的地址算法从 `mirror(clamp(ij+d))` 换成 `clamp(ij+d)`（两者对一切输入是同一个整数，见 PROOF.json），所以 token/feature/顺序/写者全部不动。

## 2. 删掉的是什么真实工作（正常执行路径）

| 项 | 条数/站点 | 依据 |
|---|---|---|
| `nrf_mirror` 内联实例 | 20 次 `nrf_rgba` 调用（5 tap × 4 角点）不再走 mirror | `nrf_hist_linear` 的 4 个角点读已在 `clamp(ij(+1), 0, (W-1,H-1))` 之后 |
| 32×32→64 乘（每处 `i%period`） | ISA 现存 **31 处**（`mul (16|M0) acc` 31 / `mul (16|M16) acc` 31 / `macl` 31+31 = 124 条）。其中对应历史角点的约 17–20 处消失 | `nrf_mirror` 每轴 1 次取模；27 次调用 = 54 轴，被 CSE 到 31 处 |
| 取模修正（符号处理） | 每处约 6 条：`add`/`add3`/`cmp`/`sel`/`xor`/`jmpi` | ISA 189–201 行形态 |
| 反射选择（`period-1-j`） | 每轴 1 `cmp` + 1 `add` + 1 `sel` | 同上 |
| `period = 2*size` 的 `shl` | 每轴 1 条 | 同上 |
| **合计** | **预计 -170 ~ -200 条（上限 -300，含被删的反射/符号修正）** | 见 NATIVE-PREDICTION 的判据 |

**没有删**（逐条声明，防止把“看起来像工作”的当收益）：

* 消息（send）**一条都不删**：gather 仍是 73 条 `load.ugm.d32`，地址值不变，顺序不变。
* 任何 `mov hf←f` 舍入点（入口 24 条）不动。
* 任何 `mix`/`fract`/`floor`/除法（`math.inv` 13 条 + Newton `mad`）不动。
* SLM 往返（2 写 + 2 读）、`fence.slm`、`signal barrier`、`sync.allrd/allwr` 不动。
* 调试块（1501 条）不动。
* `nrf_rgba` 本身保留（源像素读仍然需要 mirror，`nrf_depth_at`/`nrf_motion_uv` 也保留自己的 mirror）。

## 3. 重叠：现在的生产者/消费者/覆盖顺序（本卡前后一致）

| 数据 | 生产者 | 最后消费者 | 覆盖者（WAR/WAW） | 依赖 |
|---|---|---|---|---|
| A 片段（16 token × 16 feature，寄存器 `fa0/fa1`） | 本 SG 的 `lane<16` 写 shK，随即 `coopMatLoad` 读入寄存器 | `nrf_lift` 的 4 次 `dpas`（`fa0·w`、`fa1·w`） | 无（读入寄存器后 shK 该区间才被 K 写入覆盖） | RAW：pack → barrier → load |
| shK（2048 half） | ① feature pack（0–1023）② K（`0+sg·256`、`1024+sg·256`） | ① A 片段 ② `QKᵀ` matmul 的 B 片段 | feature 区被 K 覆盖 = WAR，已被“先 load 后 store”顺序保护 | RAW/WAR 都不变 |
| shV（2048 half） | `v00/v01/v10/v11` 的 4 次 `coopMatStore` | `ctx` matmul 的 B 片段（`load.slm.d64x64t` ×16） | 无 | RAW（`barrier()` 之前写、之后读） |
| shResidual（512 half） | `y11`（每 SG 128 half，SG 内私有） | `oc11` 的初值 `coopMatLoad(residual, shResidual, sg·128)` | 无（区间按 SG 划分） | RAW，同 SG |
| norm/den（`full_norm`） | q/k 的 f16 平方和 → 4 次 `shuffleXor(8,4,2,1)` + `broadcast(lane&16)` | 紧随的 q/k 缩放（`qr=q·n.x`、`k=n.y·k`） | 无 | 纯寄存器，无内存 |
| gather 像素（`f[]`） | 无（只读） | 本 lane 的 `packed[7..9]` | 无 | 只读；本卡改的只是**地址算式**，不移动读点 |

结论：本卡**不改变任何 A/B/acc/残差/norm 的生产者、最后消费者与覆盖者**，重叠结构逐项相同；RAW/WAR/WAW 三类都不新增也不延后。

## 5. 是否真落到 native：可观察点与“看不到即未实现”的判据

详见 `NATIVE-PREDICTION.md`。核心三条（全部在 ordinal 0 的 kernel 内，PCI/IGA 可直接数）：

1. `mul (16|M0) acc`（32×32→64 乘的低半）+ `macl (16|M0)`：基线**31 / 31**，预测 **≤14 / ≤14**（源像素 2 + 深度 10 + 运动 2 = 14 轴取模）。
2. `load.ugm.d32.a32.bss` 的 3 组（`[a0.0]` 28 / `[A+0x4]` 23 / `[A+0x8]` 22，合计 73）**必须仍是 73**，且地址立即数分布不变。
3. `math.inv` 13、`mov …:hf` 的 `hf←f` 24、`dpas.8x8` 132、`send.ugm` 热路径 306 **必须全部不变**。

若 1 看不到下降 → 归 A（实现未落地），不许用整体毫秒反推机制有效。

Convention: identical to the parent's own `sX*sWe[128]` / `sE*sWc[32]` folding — the
activation scale is static per tensor, so it is folded into the per-channel dequant factor
at pack time and the kernel performs **one** multiply per (channel, token).
`invY` is stored separately because the kernel needs it to quantise Y.
`sY = 1/invY`, `sW[o] = amax_k|W[o,k]|/127`, `dq[o] = sY*sW[o]`.

## 3. Rounding points

1. activation: `real * invY`, RNE (`roundEven`), clamp to ±127, one conversion per element
   (`nr_i8_put_y` → `nr_i8_code`, the parent's existing code point);
2. integer accumulation: exact int32, **no** rounding;
3. dequant: one FP32 multiply `acc * fsc[...]`;
4. final narrow: **one** `nrh_narrow` (FP32 → half) per fragment, in the same place as the
   parent's narrow, so the downstream norm/score path keeps its bit widths.

## 4. Residual / seed

QKV has no residual: the parent starts from `NRH_C(0.0)` and so does the candidate
(`za = I8C(0)`). The contract seed `H(X*rs)` and the projection residual `H(Y*ars)` are
untouched (they are the expand/contract and output segments' business).

## 5. EPILOGUE OF THIS SEGMENT (new INT8 reference)

```
q[k] = clamp(roundEven(float(Y_half[c,t]) * invY), -127, 127)              // once per tensor
acc[o,t] = Σ_c qW[o,c] * q[k]                                (int32, exact)
out_half[o,t] = half( float(acc[o,t]) * (sY * sW[o]) )
```

## 6. Known gaps of this segment

1. `invY` is calibrated from **one** captured tile of **one** frame (block1 only). A
   per-tensor activation scale over a 32-channel/16-token tile wastes range: per-token
   scaling is the stage-2 item (`B0/C2` register path) and needs a cross-lane amax.
2. The other six R02 passes still run the parent module (their `invY` is uncalibrated), so
   the *frame* is not yet all-INT8 in this segment for blocks 2,3,4,67,68,69.
3. One shared publication barrier pair was added; the sY8 tile is not yet aliased onto the
   dead `sX8` region (that is the B1 card's subject), so declared shared grew by 2048 B.

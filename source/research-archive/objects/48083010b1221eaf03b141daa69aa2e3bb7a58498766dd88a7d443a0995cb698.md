## 1. 为什么父是 2 个站点（可复核的推导）

源码里系数读只写了一次，但它在两迭代的 `for(group=0..1)` 里；驱动把该循环展开成两份
（n12 的 ISA 在去掉树分支后仍是 7498 行、group 副本依旧存在），于是：

```
group 0 Q 段: 0x16EA0 flat[A+0x48](p2.z) → 0x16F00 add(head) → 0x16F20 shl 2 → 0x16F40 bss load → 0x16FE0 conv → 8×mul
group 0 发布: 16 条 store.ugm（h0/h1 两侧 × 8 行）+ dbg 块
group 1 Q 段: 0x180F0 flat[A+0x48] → 0x18150 add → 0x18170 shl → 0x18190 bss load → 0x18230 conv → 8×mul
```

两份之间隔着 group 0 的 qkv store；`Scales` 是 readonly，但编译器不能证明 `QKV` 不与之别名，
所以不能把读跨过 store 做 CSE。**同一个地址、同一个值，读两次**——这就是本卡要删的那一次。
`head` 寄存器由 prolog 的 `and r116.x, gy, 31` 给出（= `(n0%1024)/32`），与本卡证明的
`p2.z + gy` 一致。

## 3. 为什么"应该"是这个数（可复核）

- **#1 的 1**：候选源码在 `for(group)` 之前读一次；SPIR-V 里 Scales `OpLoad` 只有 1 条且在
  preheader（**无** enclosing loop；父在 group 循环内，见 `evidence/SCALE-LOAD.json`）。
  驱动展开循环时只能复制循环体，不能复制 preheader，所以静态站点只能是 1。
- **#5 的 −2**：父的两个站点各是一条 `send.ugm`；删掉第二份的 bss 读与 flat 读 = −2，
  其它 `send` 一律不动（矩阵段、store 段未改）。
- **#10 的 −7**：第二份 Q 段消失的 7 条 = `mov r1.q` + `mov a0` + `flat` + `add` + `shl` + `bss`
  + `conv`；守卫若不被谓词化再加 2 条（`mov f?, r116.?` + `(W&f) jmpi`）。
- **#4 的 16**：候选的 8 个局部 `OpLoad` 在 group 循环体（块 494），驱动展开后变成 8+8 条乘法读
  同一个循环外定义的寄存器；父的两份各自从自己的 conv 取 half。
- **#8 的 0/0**：n12 的改动逐字保留（源码父即 n12 候选，`SOURCE-DIFF.patch` 只动系数读）；
  callee 序列 26 个调用完全相同、`OpFunctionCall` 26→26。

## 4. 不期望看到的东西（防止过度解读）

- 不期望 `dpas` / `mul` / `math.rsqt` 变化：矩阵段与缩放乘法一行未动。
- 不期望 F14 之外任何 pipeline 变化：plan 只在链头上替换 8 行 F14 路径（`evidence/PLAN.json`）。
- 不期望单 dispatch GpuTime 大幅改善：系数读是 7,498 条指令里的一条 `send.ugm`；
  若有人报告"F14 单点快了 5%"，先怀疑捕获串扰/时钟漂移。
- **不要**把静态 −2 条 `send` 换算成毫秒，也不要把 n12 的 −0.006942 ms 与本卡相加。

## 6. 风险与备选解释

1. **驱动重物化（A 类风险）**：若寄存器压力或调度把读重新沉回第二份，站点仍是 2。
   这不是"方向无效"，是本卡未落地；备选写法见 RESUME §4（把 4 个 half 的缩放整体前移）。
2. **守卫成本**：`n0<1024` 谓词在父 ISA 里已经是 0/1 标量（prolog 物化），守卫很可能复用；
   若新捕获出现 `cmp` +1 与 `jmpi` +2，属预期成本，不改变硬判据。
3. **活值跨 store**：一个 half 值跨 group 0 的 16 条 store 存活，最多占 1 个 GRF word；
   若 max_r 上升或出现 spill → B 类，需换写法（把系数值提前乘进 `inv`? 不允许改数学，故只能改调度位置）。
4. **包内归因**：cand 臂同时含 n12 改动。两面签名不重叠（n12: goto/join、r[a0]；本卡: 标量站点），
   所以一份 ISA 可以同时确认两面；但**毫秒不可拆**，只能整体按 F14 包记。

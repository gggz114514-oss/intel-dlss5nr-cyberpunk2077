## 结论口径

- A1 / A2 / B1 / B2 / B3 / C2 都是**结构上成立、收益未测**的独立改动；每张卡都可单独进 GPU 门。
- 组合规则：A1 与 A2 同属 D034 族，**必须先各自单卡过门**（A1 改的是"没人读的写"，A2 改的是 PASS 数与 PUSH，
  两者混在一个臂里出了首差就分不清是谁的）。
- B1 / B2 / C2 都改 INT8 共享内存且都落在 10–18 KiB 区间，**不要**在没有单卡时序的情况下直接相加；
  C2 与 B1 都动 body1 的 E/X 侧，二者**互斥**，不能同时进一个臂。
- 任何"1.17 ms / 4.93%"之类的历史数字都不属于这些卡，不得引用。

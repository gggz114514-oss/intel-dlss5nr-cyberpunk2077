# U09 整族（nrh_join_rows_to_B 重复 shuffle 合并）：构建、数值门与普通测速裁决

日期：2026-10-21。研究父：B5-plus-selected-v1，plan SHA `a0ae347fc76758ee354cc258f11abfcb804ed6e00f61a68c177042d90ddfb517`，265 发。本报告只覆盖 U09；不改冻结父、权重、Small/INT8/游戏/稳定包。

## 1. 改动与身份

现役 8 个族的 include 各自含同形 `nrh_join_rows_to_B`：对 `f0p0/f0p1/f1p0/f1p1` 四个 packed uint，为取 `.x`/`.y` 各调用一次 `subgroupShuffle`，源码层 8 次 shuffle、8 次 `nrh_unpack2`，四对完全重复（同 value、同 lane 表达式）。

候选把 lane 表达式 `(((gl_SubgroupInvocationID&1u)<<4u)^((gl_SubgroupInvocationID&30u)>>1u))` 只算一次，每个 packed uint 只 shuffle 一次、只 unpack 一次，按原顺序写出 `o[2j]=u.x; o[2j+1]=u.y`。**不改** `nrh_pack2`/`nrh_unpack2` 本体、不改整数 bitcast 与 half 舍入、不扩展到 `nrh_transpose_to_B`、不改任何调用点与其 SG 有效性条件。

变换由 `build/zcode-fp16-compute-backend-20261021/scripts/u09_join_transform.py` 从每个父 include **程序化提取函数体**后重写（不靠硬编码文本匹配），因此 8 个族用的是同一条规则，且"唯一文本差异在该函数内"可证。

### 1.1 F30 阻断的根因与解除（工具 id 解析缺陷，不是放宽校验）

取证代理（D）逐 id 定位到真正根因：`spv_tools.defining_instruction()`（`build/amd-netorg-layout-f2-workbuddy-20261016/spv_tools.py:65–76`）的 `elif len(ops) > 1 and ops[1] == cid` 分支也会匹配**不产生结果 id 的指令**。模块第 13 条指令是 `OpSource`（GLSL，`ops=[2,450]`，版本字面量 **450**），于是**任何结果 id 恰为 450 的值**都被解析成 `OpSource`，其结构签名塌成 `('op',3)`。U09 把 join helper 从 243 压到 136 指令，其后所有结果 id 前移 88，正好有一个被装饰位点落到 450。69 个位点里 **68 过、1 败**，且碰撞发生在**子侧解析**——换任何父都消不掉。

处置：**不改共享工具、不放宽签名比较**，改用本线私有副本 `build/zcode-fp16-compute-backend-20261021/scripts/spv_tools_local.py`（唯一差异是 `defining_instruction()` 增加"该指令是否产生结果 id"的门；`RESULT_AT_ZERO_OPS` 与 `result_id_of()` 都是原文件既有定义）。用它重跑 F30：

- 基线（未打 U09 的现役源）逐字节复现绑定父 `34904338…`；
- `precision_f2` 得到 `mapped=66 / extra_epilogue=3 / final=69 / removed=52`，与部署身份的 69 点逐点相同；
- 候选 `4e101f6bac5e99733df5e3443901e370ef4564c6af71c733fdd621a78c685fde`，join shuffle 8→4，NoContraction 69/69。

F30 数值门：fixed 帧 `1755e9c2…`、feedback2 帧 `9c3e511e…`，与冻结父逐字节相同，nan/inf=0、正常退出。**F30 已验证通过数值门**，状态由 `NC_PATTERN_BLOCKED` 改为 `NUMERIC_PASS`。

## 4. 成本账

- **省**：每个 helper 调用少 4 次 `subgroupShuffle`、4 次 `nrh_unpack2`、以及重复 lane 表达式（SHL/SHR/XOR/AND）。SPIR-V 侧 = −4 shuffle、−4 OpFunctionCall(unpack2)、−7 SHL/−7 SHR/−7 XOR/−14 AND、−26 OpLoad/−19 OpStore（Function 局部）。
- **增**：0。保留的 4 个 shuffle/unpack 复用原寄存器；无新增矩阵计算、无新增地址计算、无新增 SLM 读写、无新增 barrier、无新增 scratch、无新增全局运输、无新增 active SG/尾部工作。
- 静态指令减少不作为收益依据；上表时间才是依据。未采硬件计数器，**不声称** MOV/搬运的 native 计数变化。

# C32 family norm owner experiment

Baseline: ../f20-score-owner/plan.txt, SHA256 d655b6b16c1c7949d912812e84748c503c33278a8f32f5fe12438de2d510e666. Preserve accepted baseline; no deployment.

## Change and proof

Body (7 passes), F01 and F2 already normalize register fragments. Their identical full_norm computes the same ordered Q and K reductions in every lane of a 16-lane row. The builder symbolically checks the ordered XOR8/4/2/1 trees. Even lanes now compute Q inverse square root, odd lanes K, then exchange the half coefficient with XOR1. The square/FMA/reduction tree, floor, f32 inverse square root, half narrowing and callers remain unchanged. XOR1 stays inside each row. This is inverse-square-root ownership redistribution, not elimination of all norm arithmetic.

F20 uses the existing compact-pairs candidate: original scalar norm arithmetic/owners preserved, coefficients stored as adjacent Q/K half pairs; Q remains in its producer fragment, K scaling uses shared memory. The F20 candidate has instrumented local timing support but no previously established uninstrumented net gain. The combined experiment tests all 10 C32 passes together; component savings must not be summed.

## Native review

Main independently checked the three individual fixed/fb2 frame hashes and native captures. Each of body/F01/F2 changes math.rsqt 16 to 8, MOV +14, SEL -16, total static instruction count -10. DPAS, SLM/UGM send and barrier counts unchanged. No scratch instructions found. Both body pipeline identities were reviewed. Static counts include alternate paths; they are not cycle measurements. Actual allocation/occupancy are not inferred from the maximum register number. Driver scratch is checked separately on the combination.

## Why F20 cannot simply copy body norm

The current F20 candidate produces eight rows per subgroup, whereas original scalar norm threads 0..63 own Q rows and 64..127 own K rows. The first Q norm subgroup therefore consumes rows produced by four subgroups. Registers cannot be read across subgroups. Keeping these owners requires a shared handoff; removing it requires moving norm ownership to the QKV producers. A prior half-active local-owner candidate passed numerics without proven net gain; a distributed full-lane candidate failed exact numerics. Neither is silently reused as a proven faster replacement.

The body norm also has explicit column-15 FMA handling. It is not evidence that the same arithmetic reproduces F20's scalar/JIT contract. Gathering whole rows into one lane could add many shuffles and extend fragment lifetimes. A new F20 register-only norm requires a separate ordered arithmetic and owner proof, not a function substitution.

## Acceptance

Individual fixed/fb2 gates and native first; combined fixed/fb2 and driver resources next. All 40 pipeline scratch allocations must not increase; target pipelines 0,1,2,37,38 must remain zero. Only then run three alternating process pairs of uninstrumented warm1/reps30/feedback, keep all 180 samples, and compute the 95% t interval over three paired process means. No repeated identical batches to seek significance. No performance adoption from instrumented local timing or static counts alone.

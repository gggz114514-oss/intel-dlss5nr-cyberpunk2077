# NATIVE-PREDICTION — n04b-f05-c128-feed（预测 + 判据，不声称已实现）

本卡无 GPU。下面每一条都是"**期望在 ISA 里看到什么**"和"**看不到就等于什么**"。
采集方式：`native` 臂（GTPin + nativemap，`--dump_isa`），目标 PASS = 本组 ordinal 19
（12 个 PASS 复用同一 SPV，任一即可）。基线 ISA 参照
`f05-kv-consumer-layout/family/captures/native-f20-pixel-owner/ISA/CS_asmf98d5ab4…_a_9_orig.asm`
（4812 指令 / mov 2027 / send 518 / dpas 128 / scratch 0 / WG mem 24576）。

候选的 SPIR-V **代码指令数完全等于父（2692）**，所以本候选只能通过 IGC 的寄存器分配与
调度响应落地。这一点是判据设计的前提：**如果 native 的逐类计数全同，就说明 IGC 对这个
源级顺序完全没有响应，本卡判 A（实现未落地），不是方法无效。**

---

## N1 — AAR 落地：六个累加器在收尾段入口全部退休

**期望看到**

- 六个 f32 累加器 bank（8×16 f32 = 8 个 GRF/个；父样本里是 `r4/r12/r20/r28/r36/r52` 这一族）
  的**最后一次读**全部落在收尾段的窄化块内，并且窄化块是连续的 6 组。
- 父里 `accV0/accV1` 的最后一次读到其窄化指令之间，隔着 Q/K 的 norm（`shfl`/`inversesqrt`/`mufu`）
  与 4 条 SLM 发布（`store.slm`）；候选里这段间距必须缩到 ≤2 条指令。
- 收尾段**第一条 `store.slm`（V 发布）出现在 `shfl`/`mufu` 之前**。

**看不到就等于**：IGC 把 V 的窄化仍排在 Q/K 发布之后（源级顺序未被采用）→ **A 类（实现未落地）**，
把"A 退休顺序"从可试列表移除，不推广为"生命周期分离无效"。

## N2 — APB 落地：A 流地址是单一仿射标量

**期望看到**

- A 片段的 8 条行 send 的地址寄存器链，全部由**同一个** per-panel 基址标量加立即数构成
  （父里已经出现 `add (1|M0) r107.0 r1.12 1312:w` 这类 base+imm，因此**预期增量接近 0**）。
- 一个 panel 内，`mul`/`shl` 类地址指令数不增加；若减少，最多减少到每 send 1 条。

**看不到就等于**：地址本来就已经是下界（与 N15 判据一致）→ 本条**不单独开卡**，
只作为"该站点地址已是 base+imm"的又一次确认。

## N3 — 相位交界重叠（可区分点，非承诺）

**期望看到**

- phase1 的第一条 A 行 send（或多条）在 phase0 收尾段的 6 条发布**之前**发出；
  即在 `store.slm` 群里穿插 `send.ugm …d32x8t`。
- 父的行为：A 行 send 与相位收尾分离，phase1 的 A 在收尾段之后才开始。

**看不到就等于**：收尾段与下一相位的 A 发布仍被串行化；这是"本候选把退休点前移但没有
换来交错"的负结果，归 C/D 类（当前身份无净收益 / 未检出收益），并作为"下一处代码改动"
的依据（见 RESUME）。

## N4 — 必须保持不变的不变量（任何偏离都是副作用，入 B 类账）

| 不变量 | 父值（基线 native 实测） | 判据 |
|---|---|---|
| `send.ugm` 站点 | 412 | 必须相等 |
| `dpas` 站点 | 128 | 必须相等（96 QKV + 32 PV） |
| A 行 send（`load.ugm.d32x8t`，32 B） | 257 = 128 QKV + 128 PV + 1 | 必须相等 |
| A 上半区组装 `mov (8|M0) rX.8 rY.0` | 64 | 必须相等 |
| 权重返回（`rd:8`，512 B） | 104（96 = 2×48 QKV） | 必须相等 |
| `store.slm` / `load.slm` / `fence.slm` | 68 / 35 / 1 | 必须相等 |
| barrier | 1 | 必须相等 |
| Workgroup memory | 24576 B | 必须相等 |
| scratch | 0 | 必须为 0（父为 0，合同要求不得增加） |
| 每 acc 的 K 顺序 | ki = 0..7，每 K16 一条 DPAS | 反汇编顺序必须与父逐条一致 |
| 舍入点 | 每输出 tile 一次 MC→MH；norm/exp/den 表达式不变 | 数值门（fixed + fb2）必须 gold |

## N5 — 副作用观察窗口

若 N4 有任一项变化，按下面顺序归因（不许含糊）：

1. `mov` 上升 → 新增复制（候选的两个作用域变量被分配成两份而非复用）→ B 类，先修作用域。
2. `sync.*` 上升 → 退休点前移引入了新的 scoreboard 等待 → B 类，记账后针对最大项修一版。
3. `scratch` > 0 → 分配溢出 → 立即停止该身份（不是方向证伪）。
4. `Workgroup memory` 变化 → 源级错误（本候选不动 SLM）。

## N6 — 时间预测（明确写出，便于事后对照）

- 预期：**INDISTINCT**（|Δ| < 0.10 ms，与 phase1-only 双 A 的 95% 区间同量级）。
  理由：SPIR-V 指令数不变；QKV 阶段只占全核 25%；本候选只挪动退休点。
- 若出现 ≥0.10 ms 的同向、六组一致收益 → 归因到"累加器退休点前移改善了相位交界重叠"，
  并要求用 N3 的 ISA 证据支撑，不许用整体收益反推单条指令因果。
- 若出现同向变慢 → B 类（峰值 +4 或分配变差），按 §N5 第 1/2 条修一版。

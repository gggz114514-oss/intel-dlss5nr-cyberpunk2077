# OWNER-MAPPING：坐标、owner 与生产消费关系

## 片段坐标（Intel B580 实测，register_handoff.glsl / 基线源码双确认）

NRH_CH / NRH_A / NRH_C（8×16，4 分量/lane）：
- element(row, col) ← lane l、分量 c：`row = 2c + (l>>4)`，`col = l & 15`。
- 逆映射：element(row,col) 在 lane `col + 16*(row&1)` 的分量 `row>>1`。
- **CH→A 同映射**（nrh_coord_CH == nrh_coord_A）→ nrh_to_A 是纯寄存器改名（T3 变体下
  无 shuffle、无 pack）。这是 Intel C→A 直交的物理基础。
- NRH_B（16×16，8 分量/lane）：`x = (l<<3)|c`，coord 由 nrh_coord_B 给出。

## body（kv-tile，128 线程=4 SG，t0=sg*16）

- 每 SG：输入 4 个 NRH_CH x 片段（16 token×32 ch），FFN 8 块流式（ec0/ec1→act→ea0/ea1
  →ny00..ny11 累加器），contract 输出 y00..y11 寄存器→C→A→QKV（Q/K/V 寄存器）。
- norm：full_norm 每 lane 计算同 token 的 Q、K 两个归约（XOR8/4/2/1，col=lane&15，
  col==15 显式 FMA 特例）；scale 在寄存器（Q 乘 norm→half→headscale→half）。
- K：LCOL 存 shK（B-ready K^T）；V：LROW 存 shV；Q 全程寄存器。
- 唯一正常路径屏障：L576（K/V 跨 SG 发布）。score 8 K-tile、PV 8 V-tile，均单次读取。

## F01（f1c32_image_pre，128 线程）

= body 核心 + 入口 nrf_prepare_B（16 token 特征在寄存器组 B）+ nrf_lift（2×2 权重组）
+ 出口 nr_pool_natural（2×2 mean，XOR16/XOR1）。**y11 经 shResidual[512] 防溢出交接**
（生产后立即发布，QKV 仍用寄存器 ya11，输出投影从 shResidual 读回做 seed）。

## F2（f2c32_block66_fused，128 线程）

= nrf2_project_and_blend 入口 + body 核心。norm 用 nr_norm32_pair（4 片段寄存器对，
parity 分支保 col-15 FMA 契约）。无 shResidual（y11 寄存器常驻至 seed）。

## 本轮尝试改变的 owner 关系（C02 候选族）

- pair 变体：行 r（Q 或 K）→ 生产子组 SG r/8 的 lane 对 (2k,2k+1)；XOR1 交换 16 个
  平方；两 lane 各自以原操作数序构成 a/b/s/t4/t2/sum；各 scale 自己的 16 通道。
- c02b/c02d 变体：保留基线 1 线程/行结构，n 留寄存器，行内 32 值就地 scale。
- 两者均通过 SPV/CPU 检查、均死于 fixed 门同一结构化差分（见 RESULTS.md C02）。

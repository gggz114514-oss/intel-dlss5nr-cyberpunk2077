# 52-INT8 并行子代理回合：QK 整数化（数值 PASS / 性能负）、C256 v4、block31、split16 侦察（2026-10-19）

承接 `reports/49`（alpha CLEAR）、`reports/51`（qkv 内外层 CLEAR）。本轮按"CPU 可实现部分并行"派出三个实施子代理，
主代理负责验收、独立复算、GPU 门与唯一队列。所有 GPU 臂经唯一锁 wrapper；期间锁被他线持有时只做 CPU。

## 1. attention QK 整数化（`vit-attn-int8-v1`）

**数值门 7/7 块全逐位通过**（主代理在 GPU 数据上跑，`evidence/VIT-ATTNQK-GATE.json`）：
- qQ/qK 码 294,912 + 294,912 全等；score 的 160 个 WG 校验和全等；head0 全量 score 288×320、P 16×320、den 288×32、inv 288×32、qT 16×32 全等；
- 控制臂（qkv 写码 + 父 FP16 attention）与 `qkv2-diag` 的 A 前缀/QKV/qT/o **逐字节相同**（C7），证明 QKV 写出未被扰动；
- 全链 CPU 对照 qT 99.99966%（±1，n_gt1=0，仅描述性）。

**性能是负结果**（同批三臂 + 逐核计数器）：
- 普通整网 median 25.3554 / **25.4765** / 25.5086（B=0.2366）、mean 25.3937 / 25.4996 / 25.5379（B=0.2321）→ **UNCERTAIN（方向偏慢）**；
- 逐核：14 个 qkv+attention 核 968.3 → 1054.7 µs（**+86.4 µs**）：qkv 每块 +5…+8 µs（多写 qQ/qK），attention 每块 +6…+9 µs；
  即 K=32 的 int8 score MMA 省下的量被"qK 被 4 个 score SG 各读一遍"+"写码"吃掉；全图插桩 +0.212 ms。
- **PV 未实施**：成本设计（`PV-COST-DESIGN.md`）判负——int8 PV 要求 P 经 SLM 往返成 int8 B 片元，父核专门删过该桥
  （direct-complete 慢 33.68% 的负例），且 den 必须与 PV 共用同一份量化 P，改变既有 f16 den 合同。
- 结论：QK 保留为**具名负结果**（整数正确、无收益），不进入组合；PV 记 `NOT_IMPLEMENTED_NEGATIVE_COST`。

**主代理修正**：资源 402 的 POLICY 原为 `[117,118]`，但 qQ/qK 写在它的尾部、被 attention（120）读取。已把四个计划改为
`[117,156]`（覆盖到最后一个 attention reader），并记录该问题在已交付 alpha/qkv 计划中的同源潜伏（见 §4）。

## 2. C256 族（`c256-int8-v1`）：block48 已精确，49–55 仍差 ±1

子代理 A 修了三处真根因（我复核过）：lane 尺度被编译成 subgroup 统一值（v4 用 `coopMatLoad` stride-0 逐列因子）、
producer 用了未舍入的 fp32 累加器（v4 用 `packHalf2x16` 强制 half）、contract 的 B 载入用了 `nb*8192+k0`
而不是 `ki*1024`（v3 丢了 K tile 1–7）。

v4 臂的独立门结果：
- **block48：qX / qA / qM / Y 全部 100% 逐位**（对主代理的独立 CPU 复算）；
- blocks 49–55：qX 99.73–99.80%（±1，n_gt1=0），并级联到 qA 98.8–99.2%、qM 84–91%、Y 53–63%。
- 根因仍未闭合：producer 发出的码仍不等于 `code(已存 half)`（±1 只在 .5 边界）。**因此 C256 仍未通过门、未跑性能。**

## 4. split16 侦察（`work/.../B-recon/SPLIT16-RECON.*`）

split16 占整网插桩 19.72%（4.897 ms），l2 占其 60%（整网 11.8%）：
- **l2 S22**（QKV K=512 + QK K=32 + PV K=64，183.8 µs/块）：QKV 占 92.4% MAC → **最值得但改动最大**，只建议整数化 QKV，
  QK/PV/softmax/norm 留 FP16；A 必须每块 1 发生产者，禁止按 WG/head 重复量化；
- **l1 S21**（单静态 GEMM K=512，40.1 µs）：值得（SLM staging 重复 4 次）；
- **l0 S20**（FFN 三段，64.7 µs）：只 stage1（50% MAC）值得；stage2/3 K=64/256 不划算；
- **l3 S23**（16.1 µs，已达经验 MMA 上限）：低优先廉价副臂；**l4 S25**（22.6 µs）：跳过。
- 全静态 GEMM 减半的算术上限约 1.2–2.0 ms，但 l1/l2/l0 的 MMA 速率只有 l3 的 36–50%，保留原 staging 的 INT8 化仍受运输限制，必须实测。

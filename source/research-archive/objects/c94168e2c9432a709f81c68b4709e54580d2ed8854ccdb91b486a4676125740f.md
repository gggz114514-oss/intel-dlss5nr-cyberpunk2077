# DSH 全网纯静态 INT8 施工总结（2026-10-29）

施工书：`work/codex-astra-fp16-int8-audit-20261024/int8-quality-first-20261029/DSH-FULLNET-STATIC-QUANTIZATION-20261029.txt`
本报告只陈述实际产物与实测证据；**没有画质通过，没有部署，没有性能验收**。

## 0. C00 色偏首因定位（最高优先级，进行中）

施工书顶部 C00 已把“定位第一个产生/放大色偏的模块”列为最高优先级，并**禁止**用末端 RGB 增益/白平衡/LUT 掩盖。
原先的 3×3 输出校正已停止作为方案，只保留为诊断负结果。

- 观测（XE−FP16，固定 FP16 亮度分桶）：34189 亮部（Y≥0.70，2.76% 像素）R+0.0714/G−0.0143/B−0.0624；
  41444 R+0.0471/B−0.0698；43654 R−0.0236/G−0.0448/B−0.0698。B 是三帧唯一同号通道。
- 参考 B=1.0 像素占比 24.8/26.0/10.5% → 臂 1.6/2.0/0.5%；B 亏损随 B 增大（0.8–0.9 段 −11%…−20%，
  0.9–1.0 −6%…−8%，钳位处 −2%）→ **高光传递压缩**，不是常量白平衡。
- 下游替换（只换边界为对齐教师，其余不变）：block66_out → **34.409 dB（+5.10）**；
  block0/4/14/22/30/62/63/64、skip0 均 29.23–29.33（无效果）；block67/68/69 → 34.41–34.42（尾层无辜）；
  block65/F2 输入替换 28.20/28.19（布局/混合分布无效，UNRESOLVED）。
- **首个具名模块 = C64 block65**：41444 上把 block65_out 换成同帧教师 → **33.3509 dB（+3.719）**；
  block62/63/64 替换分别 29.6303/29.5874/29.4585（无改善或更差）；block66 替换 +3.759。
  说明误差在 block65 内新生，不是它之前继承的；F2 是下游放大器（两处实现错误已修，但输入已错）。
- F2 的两处实现错误（D1 A gather、D2 rc.x→rc.y）已确认并修复；同输入 A 类从 relL2 1.20 降到 0.273/0.298/0.302，
  **fix + 教师 block65 输入可得 34.35 dB**。但 fix 单独 24 帧 **-0.079 dB（9/24）**：
  static 8 帧 +0.14..+0.26，motion 帧 -0.06..-0.47；是“旧 bug 恰好抵消下游误差”的非单调传播，不是 F2 仍有错。
- block65 输出对教师只有 0.685× rms、corr 0.624；全局 WO×1.46、残差 rs×1.46、逐通道 rms 匹配都变差，
  说明不是单一 tap，而是 block65 内部的通道/尺度量化损失；正在拆它的 FFN/attention/WO 子阶段。

## 0.1 一句话结论

当前最佳候选是 `c64-family-static + F01 XE`：24 帧、捕获 FP16 history、对 FP16 输出的平均值
**29.692495 dB**（22/24 改善，34190/34192 轻微退化）。但它**不是部署画质**：同一候选用自己的输出做 history 的 8 帧自主反馈
从 29.31 掉到 **27.32 dB 稳态**（均值 27.729），原始 INT8 基线也掉到 26.69，说明反馈回灌是 INT8 链的共性问题，
当前候选的单帧优势在反馈口径下只剩 +0.058 dB（相对上一版 27.671）。全网矩阵已无 FP16 MMA、无 U8、全部 S8×S8→S32；
但动态激活尺度仍有 **223 条台账边 / 276 个 attention 实例**，pure-static 未完成。

## 3. 自主反馈（关键负结果）

同一 8 帧 34189..34196，首帧注入捕获 FP16 history，后续只把 history 平面换成前帧候选自己的输出：

| | 首帧 | 稳态 | 8 帧均值 |
|---|---:|---:|---:|
| 当前 XE 候选 | 29.3060 | 27.32 | **27.7290** |
| 上一版 c64 候选 | 29.2956 | 27.26 | 27.6706 |
| 原始 corrected INT8 | 27.6260 | 26.68 | 26.8854 |

- 当前候选第 1 步 29.31→28.10（-1.21 dB），4–5 步饱和在约 27.32；没有发散，但没有恢复。
- 基线 INT8 也掉约 0.95 dB → 反馈回灌是 INT8 共性问题；XE 的 +0.084 单帧收益在反馈下只剩 +0.058。
- history 面与显示面同源（输出 483 偏移 14,745,600、长度 14,745,600），误差原样回灌。
- 时间分析（S13 `FEEDBACK-TEMPORAL.json`）：**没有新增闪烁证据**（chain 的 temporal energy 不高于参考），
  退化是**持久的、空间集中的误差**；DC 占反馈 MSE 20.5%，top5 tile 占 29.2%，history 替换占 10.6%。
  这支持“输出颜色/DC 校正是比继续刷 FFN 更直接的杠杆”。
- **29.69 dB 不能代表部署画质；部署口径更接近 27.3 dB。** 详见 `reports/FEEDBACK-FINDING.md`。

## 4. 已停止的方案：静态输出颜色校正（仅保留为诊断）

> C00 明确禁止末端调色/白平衡/RGB 增益；本节只记录“为什么不做”，不再是候选。

在 24 帧开发集上拟合 3×3+bias 输出校正 `y' = M y + b`，固定平均矩阵做留一序列验证：

| held-out | 基线 | 校正后 | 增益 |
|---|---:|---:|---:|
| motion-01 | 29.5163 | 30.4496 | +0.9332 |
| motion-02 | 29.9936 | 30.6063 | +0.6127 |
| static-01 | 29.3166 | 30.2794 | +0.9628 |
| **平均** | | | **+0.8362** |

- 只保留对角（per-channel scale）会**变差**（-0.79/-1.27/-0.58），交叉通道项是必要的。
- 后验应用到 8 帧反馈输出：27.6706→28.5308（+0.8602）；真实折进权重后 history 也会变，需重跑。
- **S03 的折叠结论**：精确 weight-only 折叠**不可行**。出口是 `clamp(base + residual*0.25)`，再与 history mix，
  `base` 是逐像素图像、kernel 没有 bias 项；把 3×3 折进 residual 分支只能得到 **+0.335 dB**（9 个数，
  不是 +0.84），因为 `base` 的固定点不变、常数 b 无法产生。要拿满 +0.93 必须做 **post-pass**（每像素 3×3，
  9 乘 3 加），不是 weight-only。
- **S13 的闭环模拟**：校正后 history 只比原来靠近 9–11%，留出矩阵只有 +0.650，预测折权重后闭环稳态约
  **28.19 dB**（比纯输出校正多约 +0.07），仍比单帧 30.31 低 1.69 dB。
  **颜色校正是输出级增益，不能修好反馈回路**；不要把 +0.86/+0.88 当反馈口径收益。
- 注意：这是 24 帧开发集拟合，LOO 只跨序列、不跨场景；不能称画质通过。

## 5. 逐族结论与负结果

- **F01 lift**：+0.916 dB，已采纳；16 通道均衡 + NNCF 对账，K16→K32 补零保持。
- **C32 body1-3**：局部 46.5/31.4/29.9% → 1.7/2.1/4.7%，整网 +0.168；已采纳。
- **C32 body4**：整块融合 dispatch；X 均衡局部 12.7→11.4%，E 均衡局部 FFN 11.1→4.6%，
  但整网 3/3 帧 -0.14…-0.25 dB；**否决 pack、保留 E 方向**。真实 X 与教师 X 差 21%，但 E 统计几乎不变；
  退化发生在整网响应，不在布局/尺度/tap。
- **C64 8 blocks**：局部 6.5/10.3/8.6% → 3.2/3.8/3.9%，整网 +0.051；已采纳。
- **C128 b9**：教师域 5.72→3.14%，但真实输入 `block8_out` 是 **int8 qX** 域（`pilot_common.glsl` L26-33），
  教师域标定不适用；anchor gate qX 仅 14% 码一致、Y relL2 42%，映射/DS 上游仍有错；**未闭合**。
- **C256 b15**：局部 3.42→1.55%，整网 2/3 帧轻微退化；该节点 56.5% 误差在量化前由输入决定，
  全部量化预算 0.08%，单块上限 +0.011 dB。**单块否决；要 15..22 成包（预期 +0.03..0.08）**。
- **split16 b23**：Y 0.164%→0.0507%，F 28.1%→6.97%；但 FFN 对 Y 只占 0.4–0.7%，95% 激活为 0，
  端到端杠杆很小；b24..b47 的 l0 qx 来自上一块 l3，逐通道 inverse 需另一处 shader 改动。
- **ViT b31**：教师域 2.099→1.064%，实际域 2.480→1.608%（-35%），但 3 帧整网 -0.0009 dB；
  pack A 不采纳；diag2 gate 四项逐位 true，证明 shader/布局正确，失败是目标选错 + 上游分布变化。
- **ViT attention sQ/sK 静态化**：S09 已实现并 CPU 验证（OpAtomicUMax 3→1，只留 sV）；control 与 34189 逐字节一致；
  整网 3 帧 -0.0038/-0.0081/+0.0085 dB（净 -0.0012），**几乎中性**。这是第一个真正落地的纯静态 attention 替换
  （16 个 sQ/sK site），可作为 pure-static 合规臂，但不是画质收益；sV/sP 仍未静态。
- **WO/DS/投影**：36 WO、4 DS、4 跨族投影、4 尾层；36/36 UNKNOWN 关闭，33 动态 +2 静态 +1 撤回。
  C256 b15 WO 切片局部 0.6475→0.5776%（-10.8%），但 WO 只占该块 0.65%，整网杠杆小。
- **F2/F20/b39**：全部动态；F2 可按名字对齐且真 INT8，F20 不能（阶段边界移动），b39 是 2 个 INT8 MMA。

## 6. GPU 执行与工具

- 用户在本会话明确授权占用唯一锁；执行协议：`GPU.lock` FileShare.None、单队列串行、游戏未启动、失败即停。
- 6 个批次、约 50 个单帧/局部作业；基线 `regress-c64-34189` 逐字节复现 `56318ff6…`。
- 关键工具缺陷已修：
  - PS5.1 无 `ProcessStartInfo.ArgumentList` → 改原生 `& runner @argv`；
  - 诊断 dump 必须 `POLICY <buf> 1`，否则池别名会伪造数值（S08/S05 各中一次）；
  - recheck 不能把 uint8 当 int8；
  - queue 的 `out` 必须唯一且与 wrapper 查找名一致；feedback 输出名 `feedback-network.bin`。
- 实际上游捕获（resident=1，6 个 buffer，offset 唯一）：C32 b4 20.97%、C256 b15 53.10%、
  split16 b23 58.07%、ViT b31 64.01%、C32 b67 108.5% 与教师输入不同；C128 是 int8 qX 域。
  这解释了为什么教师域局部标定不能预测整网（`reports/UPSTREAM-SHIFT.md`）。

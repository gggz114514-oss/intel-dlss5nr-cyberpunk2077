# T11 图重放：原 runner 与重放 runner 的同计划对照（含录制成本实测）

日期：2026-10-21。计划：冻结父 B5-plus-selected-v1（SHA `a0ae347f…`，265 发），两臂**同一个 shader 计划**，只换 runner。

## 1. 实现

候选 runner 源 `build/zcode-fp16-compute-backend-20261021/runner/port_network_model_runner_replay.cpp`，由 `build/gpa-b321-prep/port_network_model_runner.cpp`（pinned exe SHA `ee9796b0…`）加一个 opt-in `--replay-suffix` 得到；构建脚本 `runner/build_replay.cmd`（MSVC 14.44 BuildTools、同 Vulkan headers、从系统 `vulkan-1.dll` 生成 import lib），产物 `runner/port_network_model_runner_replay.exe` SHA `e358b8caa46bf4eae08284a0cde59ccdf4ae45c89d4b610a3a26ff906b268a19`。

分界（严格按票面）：
- **逐帧留在 primary**：query reset、TOP_OF_PIPE 时间戳、feedback 的 history 拷贝与 controls 更新、pass 0（feedback push[22]/push[23]）、以及**所有逐帧首次使用清位**。
- **预录进 secondary**：pass 1..264 的静态 push、dispatch、逐发 barrier、per-pass 时间戳。
- **关键修正**：冻结计划里有 **16 个 pooled 非驻留 buffer 的 `clearFirst=1` 且 `firstPass` 落在 80..182**（`split16_b23_T` … `split16_b47_T`、`split16_b30_pool`）。这些清位是逐帧工作，不能冻进后缀；候选把后缀在该位置切开，每个清位仍录进 primary 的对应 pass 之前，顺序与父完全一致。
- 不冻结任何逐帧字段；`saveFrames` 读回仍是独立命令；不新增 simultaneous-use。
- 新增 `record_ms`（begin 前 → 该帧 record 结束，不含循环前一次性后缀录制），`submit/wait_ms` 仍用原 `host_submit_complete_ms`，`gpu_ms` 仍用原时间戳区间。

诊断臂（全部 265 发进 secondary，`--reps 30`）：GPU 24.80/25.06/24.86 ms，与原 runner 的 24.85/25.08/24.90 ms **同批不可区分**。

结论分开报：
- **CPU 录制**：重放候选把每帧录制从"整图 265 发"降到 **0.123 ms/帧**（只录 query reset、history、pass 0、两条 timestamp 与 execute）。原 runner 的 record 成本本次另用一次实测补测（见 `perpass-*` 收据的对照口径），**不把 CPU 下降写成 GPU 收益**。
- **GPU**：分割版本 42.0–42.2 ms，比原 runner 25.4–25.7 ms **更慢**；不分割的诊断版本 GPU 与原 runner 同级。
- **端到端**：重放分割版每帧 host_submit ≈ 42 ms，原 runner ≈ 25.4 ms，端到端也更差。

## 4. 裁决

- T11 当前候选：`GATE_FAIL_OUTPUT_MISMATCH` + `TIMING_REGRESSION`。**不发布**，不并入最终组合。
- 可复用事实：把静态后缀预录成 secondary **能**把每帧 CPU 录制压到 0.12 ms 量级；但在本 runner/驱动组合下，**跨 secondary 边界重放改变了输出**，且把 265 发切进 secondary 后 GPU 反而变慢（全量 secondary 诊断臂又不慢），说明代价来自"跨边界重放"而不是 secondary 本身。
- 该结论不改变任何 shader 侧结论；U09 等 shader 收益另有独立验收。
- 失败原件保留：`run/zcode-fp16-compute-backend-20261021/{t11-repl-fixed,t11b-*,t11d-*}` 与 `exports/*.lock-receipt.json`；候选源与 exe 保留，不删。

# 51-INT8 ViT qkv 整数化闭合并通过：内层 −0.25…−0.30 ms、外层 −1.02…−1.07 ms（2026-10-19）

承接 `reports/49`（alpha 全族 CLEAR）与 `reports/50`（qkv 构建 + GPU 阻挡）。本轮把 ViT 块 32–38 的 **qkv GEMM** 也
整数化，ViT 块由此达到 **4/5 个矩阵原生 INT8**（expand / contract / projection / qkv），只余 attention 的 QK/PV。

## 1. 施工

- `contract` 顺手写 qY：在写出 FP16 Y 的同一循环里用同一寄存器值写 int8 码（一次量化、无二次读、无双写）。
- 新核 `vit_nb04_qkv_int8.comp`：A=qY int8（binding 4 的 int8 视图）、B=WQKV int8 段、INT32 累加、
  按输出通道 `aq[n]=sY·sWQKV[n]` 反量化成 half，随后**原样**进入父核的 pairRaw 暂存、每头 Q/K L2 归一化、
  5.65625 与 per-head scale、QKV 写出。零新增 dispatch、零新 buffer、ABI 不变。
- 权重包（`tools/pack_vit_block_qkv.py`）在 alpha 包上追加 WQKV int8 段（3,145,728 B @9,465,920）、`aq[3072]`、
  `ws[11]=sY/ws[12]=invY`；FP16 WQKV/WO/gains 段逐字节保留。

## 2. 数值门（7 块，全部逐位 100%）

| 张量 | 规模/块 | 参照 |
| --- | --- | --- |
| qY | 294,912 码 | 独立 CPU 复算 `clamp(RNE(f32(Y·invY)))`（Y 取本臂实际 dump） |
| QKV | 884,736 half | 独立 CPU：int8 GEMM + 逐 op float16 归一化仿真（先用**父臂数据**自检：rel_l2 7.2e-06、逐位 99.95%） |
| qT | 294,912 码 | 逐块控制臂（同链、该块 attention 写出还原父 FP16）精确 requant |
| o | 294,576 half | 全 CPU 链（qT 参照 → WO int8 → 残差 FMA） |
| 上游同一性 | — | 每块控制臂的 Y/QKV 与主臂逐字节相同；block32 的 Y 与 alpha 臂逐字节相同 |

## 3. 性能（同批五臂：v7父 → alpha → qkv → alpha → v7父，30 样本，`--pool --warm 1 --reps 30 --feedback`）

- **外层（对 v7 父）** median 26.1199 / **25.0617** / 26.0830（B=0.1485）、mean 26.1204 / **25.0526** / 26.0927（B=0.1439）
  → 双统计 **CLEAR_FASTER，−1.02…−1.07 ms（≈4%）**。
- **内层（对 alpha，隔离 qkv 增量）** median 25.3077 / **25.0617** / 25.3257（B=0.1503）、mean 25.3443 / **25.0526** / 25.3539（B=0.1460）
  → **CLEAR_FASTER，−0.25…−0.30 ms**。
- 逐核（与 alpha 同臂型隔离，单次插桩描述性）：7 个 qkv 核 91.4 → 62.6 µs（各 −26.8…−32.4 µs，≈**−31%**），
  7 个 contract 不变（±1.2 µs 噪声）；全图插桩 23.886 → 23.808 ms（−0.078 ms，含跨臂噪声，不作收益口径）。

## 4. 事故、更正与污染批次（原件全部保留）

1. **v1 全零 bug**：新头把 `w8` 尺寸写成 9,465,920（实为 wqkv8 起始偏移），尾巴整体后移 73,728 B，B 操作数读全零
   → 臂 `qkv-diag-001`/`qkv-ctrlattn-b*` 的 QKV 全 0。首版 SPV 存为 `vit_nb04_qkv_int8_v1_allzero_bug.spv`；
   修正如 `…_v2.spv`（`6eb17d76…`），计划改指 v2，全臂换新标签 `qkv2-*` 重跑。
2. **污染批次**：`qkv2-ord-*` 三臂出现父前后 52.4 vs 26.7 ms（游戏会话后 GPU 状态未回稳；同期 FP16-009 线各臂
   26.2–26.6 ms 属正常）。该批**作废但样本保留**；加预热臂后以 `qkv3-*` 重跑（父前后 26.06/26.09 一致），
   再以 `qkv4-ab-*` 五臂完成内外层裁决。
3. GPU 唯一锁 14:53–18:08 由 Small 线游戏内测试持有：期间按纪律只做 CPU（构建/自检/侦察），
   后台队列守候重试 232 次后超时；锁释放后所有臂经同一 wrapper 串行执行，未抢锁、未杀进程。

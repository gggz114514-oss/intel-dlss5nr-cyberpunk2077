5. 下一处具体代码改动（按优先级，全部不在本卡实施）
====================================================================
5.1 [F11 降级版 A′，如果判 A/B] 只折 epilogue、不动环内：
    保留 `ob` + 常量 {0,8,8192,8200}，把 `wo/xo0/xo1` 三个跨环标量删掉，环内回到
    `wbase+(k/16u)*256u` 写法。用于把“epilogue 地址折叠”与“环内强度削减”两项贡献分开。
    预期：ISA 若仍与父一致 ⇒ 结论“F11 地址层无空间”，转 5.2。

5.2 [F11 第二方向：成对权重跨 M 块复用，必须单独开卡]
    当前每 SG：a0/a1 两个权重片段供 2 个 token 组（4 DPAS）。改为供 4 个 token 组：
      for k: load a0,a1;  load b0,b1,b2,b3;  c0j+=a0*bj; c1j+=a1*bj (j=0..3)  ⇒ 每步 6 load / 8 DPAS
    权重读取量减半（每 SG 覆盖 64 token × 16 channel 而非 32 token），但：
      (i) 累加器 8×8×16 f32 = 每线程 32 个 GRF 数据寄存器（父 16 个）——必须给活值峰值账；
      (ii) token 维 grid.x 33 → 17（1056/64 = 16.5），**出现半 tile**，必须补尾域证明
           （尾块 16 token 走原 4-acc 路径或 predicate store）；
      (iii) 不得与 store 折叠同一次首次修改（本合同明令）。
    先做静态：把 DPAS/load 计数与 scratch 0 作为门；再做 native。

5.3 [F09 的 SLM 往返删除，作为下一张卡的具名改动——比 F11 的空间大得多]
    族内文件：candidates/zcode-fp16-b5-global-expansion-20261020/split16-s21-seed-direct-v1/source/
              split16_projection_fp16.comp（KIND==1，即 split16_b*_l1 的 16 个 PASS）
    现状（正常路径，非 debug）：
      for(uint e=lid;e<8192u;e+=256u) { uint t=token_at(e/512u),c=e%512u; sx[e]=gt[tiled(t,c,512u)]; }
      barrier();
      …… 环内 coopMatLoad(a, sx, m0*512u+k, 512u, ROW)
      ⇒ 每个 WG 把 16 token × 512 channel = 8192 half = 16 KiB 从 global 抄进 shared，
        外加 1 道 WG barrier，只为把地址换成 stride-512。
    具体改动：删掉 sx 暂存与 barrier，环内直接
      coopMatLoad(a, gt, tiled(token_at(m0),0u,512u)+((k/16u)*256u), 16u, ROW)
      （与 F11 的消费者 ordinal 64 完全同形：ROW stride 16，行 = token，列 = channel）。
    等价性：sx[m0*512+k+r*512+c] = gt[tiled(token_at(m0)+r, k+c,512)]
            = gt[tiled(token_at(m0),0,512) + (k/16)*256 + r*16 + c]（token_at 连续，16|m0，k%16=0）
            ⇒ 逐字节相同，K 序相同。
    预期删除：264 WG/pass × 16 KiB = 4.1 MiB SLM 写 + 4.1 MiB SLM 读 + 264 道 barrier（每 pass）；
              16 个 PASS ⇒ 约 66 MiB / 帧的 shared 往返 + 16 次派发内 barrier。
    注意：F09 需要全 512 输入、前级每组只产 64，融合不得让每个输出 owner 重算前级 FFN；
          本改动只删本 PASS 自己的 sx 暂存，不动跨 group 供料。

5.4 [F12] b30_l3/l4（ordinal 91,92）：最后域转换不是普通投影，折叠 repack 须同时改

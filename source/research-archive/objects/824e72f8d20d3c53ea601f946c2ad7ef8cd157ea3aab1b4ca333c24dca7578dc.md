# C00 可替换边界清单（A 类入选 / 非 A 类排除）与逐边界“换了哪些边”

本卡只回答一件事：**把某个疑似边界改成对齐的 FP16 教师张量、其余链不动，最终固定 ROI 的 RGB 偏差是否下降**。
不做调色、不做输出修正、不改共享 plan、不跑 GPU。计划全部由 `build_plans.py` 用 `tools/planlib.py` 生成并 `validate()`。

## 1. 入选判据（三条全过才算可替换）

1. **半精度语义**：候选里该 buffer 的字节数 == 教师 dump 字节数（`dump_<name>.bin`），即 2 B/元素；且与现役 FP16 plan 同名 buffer 同尺寸。
2. **同布局**：同名、同尺寸、同图位置，且 FP16 dump 由同一 dump 管线在该 buffer 名上产出（`dump-fp16/receipt` 的 `original_plan_rows=152 / gpu_passes=232`）。
3. **只读消费者存在**：至少有一个 dispatch 只**读**它（排除“4 pass 累加器被自己写”的伪消费者）。

## 2. 全量普查（34189，候选 906 buffers vs `dump-fp16` 的 dump 名）

- 同名 dump：**274**；尺寸相同（可作半精度替换）= **267**；尺寸不同 = **7**。
- 7 个不可替换：`block8_out`、`block9_out`、`block10_out`（均为 2064384 B = 教师 4128768 B 的 0.5×，**int8 qX**），`swin_9_M`、`swin_10_M`、`swin_11_M`、`ioport_70_ioport_body`（尺寸不匹配，int8/packed 中间量）。
- 结论：**int8 qX 边界不得硬塞 half**。要得到它们的教师对照，必须另建 producer（用静态 qX 尺度把教师 half 量化成 int8）或另建参考臂；这不在本卡范围，登记为缺口。

## 5. 读数汇总（本卡 CPU 复核）

| 边界 | 结果 | 判读 |
|---|---|---|
| `block0_out` | 29.231 dB（基线 29.306） | R2：偏差不是 block1 之前新生 |
| `block4/14/22/30/62/63/64` | 29.23–29.33 dB | R2/R3 之间：多读者混合，**不能**据此排除这些模块 |
| `block65_out`(b5) | 28.20 dB | R3：无效，不作证据 |
| `block66_out` | **34.408 dB**，R/G 暖偏从 +9.1e-3/−8.1e-3 收敛到 −2.0e-3/+1.2e-3，B 仍 −7.5e-3 | R1：F2 及其上游拥有几乎全部误差；B 偏另有一处下游源 |

因此当前证据支持“**误差主要在 F2 及之前**，且颜色偏差至少有两个源（暖偏在上游、B 偏在下游）”，不支持把任何一个 B 类边界单独当唯一根因。
